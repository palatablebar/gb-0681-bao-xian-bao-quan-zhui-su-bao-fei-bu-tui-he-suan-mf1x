# 保费补退定义

每份保单有且仅有一条issue基线。change按effective、责任、version选版；同生效日同版本矛盾拒绝。cancel必须引用同保单的change，取消整份变更，不按录入顺序覆盖。区间为[start,end)。年度保费按所在自然年365或366日拆分，跨年强制切段。先求每段精确保费，再最大余额法分配到分，使段合计等于保单总额。paid为已收金额，总应收减已收为补退额，正数补缴、负数退费。

## 通用采信约定

CSV按UTF-8 BOM、UTF-8、GB18030回退，保留逻辑记录结束行号；引号内换行由CSV解析。重复表头单独计数，列数不齐隔离。编码与ID按字符串保形。缺失哨兵为 `-`、`N/A`、`NULL`、`未知` 与空串；不得作为零。数值先NFKC归一、去千分位，再用Decimal。日期采用ISO；时间必须带偏移并转UTC。空文件、全空行、仅表头分别返回EMPTY_FILE、BLANK_FILE、HEADER_ONLY。

重复键为(id,version)，完全相同行去重；同键内容冲突则整组隔离，不取最后一行。行数对账：输入=采纳+隔离+空行+重复表头+完全重复。运行幂等键由输入字节、参数与规则版本计算。

# 再保分出调整裁决（M8）

## 唯一可入账结果

追溯保全更正改变原保单保费与赔款责任后，再保分出侧形成一笔调整，字段含：原分出记录、原更正依据、原再保账期、调整期间（本期末结账单账期）、分出份额、分出保费更正前/后/差额、赔款份额更正前/后/差额、净额调整、归属去向、裁决理由。差额按 `毛额 × 分出份额` 用 Decimal 计算并按分（0.01，四舍五入）舍入。

- 原再保账期**已关闭**：审计要求的“原账期重述”**不可入账**。重述会覆盖原分出记录（覆盖后已关账期再保分出对账无法解释）并改写已关账净额。唯一可入账结果是 `current_offset`（当期冲抵）：原账不动，差额作为追溯调整进入本期末结账单，调整行逐字段携带原账期与更正依据，审计可凭以重述经济事实。
- 原再保账期**未关闭**：可在 `current_offset` 与 `original_restatement`（原账期重述）间归属。
- 两种归属的跨期净额合计恒等：`当期冲抵净额 = 开放账期重述净额 + 已关账期净额(不可变)`。守恒校验写入汇总，不平则不得结案。

## 状态机与防错

- 起点：更正已采信（`admitted=true`）但再保去向未定，调整为 `pending`；未采信更正（NOT_ADMITTED）与找不到原分出记录的更正（REFERENCE）隔离，不形成调整。
- 全部调整必须有明确归属（`all_attributed`）才允许结案下载；存在待归属返回 PENDING_ATTRIBUTION(409)。
- 幂等：调整编号由更正内容哈希确定，同一更正重跑不新增调整（INSERT OR IGNORE + skipped_duplicates）。
- 原分出记录只追加、永不覆盖：内容变更被拒绝（ORIGINAL_FROZEN,409），旧基线保留可读。
- 归属切换采用版本链：先追加新版本（active=0）再翻转 active；事务显式 `BEGIN/COMMIT/ROLLBACK`，任何异常（含注入失败）整体回滚，旧版保持 active，审计留痕。
- 持久化使用独立台账表（cession_originals / cession_adjustments / cession_audit），与直保 runs 表共库不共表。WAL 仅在数据库首次创建时设置一次——事务中执行 `PRAGMA journal_mode` 会隐式提交并使 ROLLBACK 失效。
- 复核界面（/m8_cession）与结案下载（m8 export、/api/archive 证据包）共用 `serializer.rows/export_csv` 同一投影，保证看到同一分出保费、赔款份额、调整期间与原更正依据。
